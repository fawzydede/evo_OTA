=== 01/03/2026 ===
This is Android 16 QPR2 with February 2026 security patches

Notes:
==============================
- LineageOS-based tree. Signed build.
- ROM is EROFS (Extended Read Only File System)
- You can use regular TWRP for first time flash (Flash ROM.zip -> reboot recovery -> factory reset -> reboot system)
- Updating: Settings -> System -> System Update (you can also do local update no need to enter recovery for sideload)
- ROM Shipped with ReSukiSU download manager here: https://t.me/ReSukiSU/4
